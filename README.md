# RoomBites

Full-stack campus food delivery app for real RoomBites accounts.

## Tech

- React + Vite
- Tailwind CSS
- React Router
- Framer Motion
- Axios
- Node.js + Express + MongoDB backend

## Run Frontend

```bash
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5173/
```

## Account Rules

- Students and delivery agents must register with a real `@gmail.com` email.
- Admin access is restricted to `sathwikgolla06@gmail.com`.
- Demo accounts are not supported.

## Build

```bash
npm run build
```
